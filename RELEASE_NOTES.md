## Cómo instalar

1. Descarga **Instalador-Cosmos-26.3.exe** (abajo, en *Assets*).
2. Cierra el launcher de Minecraft y ejecuta el instalador.
   - Si Windows muestra "Windows protegió tu PC": **Más información → Ejecutar de todas formas** (el instalador no está firmado).
3. Abre el launcher, elige el perfil **Cosmos 26.3** y pulsa **Jugar**.

Para conectarte al servidor necesitas Tailscale y estar en la red de Jesus.
