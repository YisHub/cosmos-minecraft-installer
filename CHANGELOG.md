# Versiones del instalador

Cada versión es un tag que GitHub Actions convierte en `Instalador-Cosmos-26.3.exe` en Releases.
Volver a ejecutar el instalador lleva un pack viejo a la última versión.

| Versión | Cambios |
|---|---|
| v1.0.6 | Paquete de traducciones **Cosmos Español** dentro del instalador, ya activado: Sodium, Punchy, Not Enough Animations, AFK Cinematics y lo que faltaba de Iris, EMF y ETF (524 textos). |
| v1.0.5 | **Cosmos Tabs 1.0.1**: páginas de pestañas, tapas de cofres que ya no quedan abiertas y entrada al servidor con o sin el mod. |
| v1.0.4 | **Punchy** (animaciones en primera persona). |
| v1.0.3 | **Cosmos Tabs 1.0.0**: ventanas de cofres movibles, pestañas, dos ventanas y cortar/pegar. |
| v1.0.2 | **Mod Menu**. |
| v1.0.1 | Animaciones: **Not Enough Animations** y **Fresh Animations** (con EMF y ETF), ya activado. |
| v1.0.0 | Primera versión: Minecraft 26.3 + Fabric Loader 0.20.1, Fabric API, Sodium, Iris con Complementary Reimagined, Cinematic Interactions, AFK Cinematics y el servidor en la lista. |
